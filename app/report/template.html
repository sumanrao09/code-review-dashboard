1. Executive Summary

This assessment identified vulnerabilities across authentication, authorization, injection, cryptography, SSRF, and configuration domains. The dominant risk theme is broken authentication and access control: several services are exploitable by an unauthenticated caller, and the platform's shared HMAC request-signing scheme provides no real authenticity because its secret key ships inside the browser bundles. Findings below exclude confirmed false positives (e.g. MD5 cache keys, non-reachable dead code, sanitized markdown rendering) verified against the source.
